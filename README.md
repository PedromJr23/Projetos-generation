
# Projetos Generation – Análise de Dados & Cálculos Nutricionais

Este repositório reúne três projetos desenvolvidos durante o curso de Análise de Dados.  
Os projetos têm foco em manipulação de dados, leitura de arquivos, lógica de programação e cálculos relacionados a saúde e nutrição.

---

## 📂 Projetos Incluídos

### 1️⃣ **Análise de Músicas**
**Pasta:** `Musicas/`  
Este projeto tem como objetivo:

- Ler arquivos CSV contendo informações musicais
- Processar e classificar os dados
- Exibir informações formatadas na tela
- Explorar conceitos de manipulação de dados na prática

**Principais habilidades demonstradas:**
- Leitura de CSV
- Estruturação de dados
- Classificação e filtros
- Uso de Python para análise simples

---

### 2️⃣ **Calculadora de Calorias, Proteínas e IMC**
**Pasta:** `Calculadora/`  
Este projeto utiliza informações nutricionais de alimentos para:

- Calcular calorias totais consumidas
- Somar proteínas ingeridas
- Calcular o IMC do usuário
- Emitir um parecer sobre a condição física com base no resultado do IMC

**Principais habilidades demonstradas:**
- Manipulação de dados tabulares
- Cálculos estatísticos
- Estruturas condicionais
- Funções modulares

---

### 3️⃣ **Cálculo de Proteínas Diário**
**Pasta:** `Proteinas/`  
Projeto focado em:

- Cálculo automático da quantidade diária recomendada de proteína
- Análise simples baseada no peso do usuário
- Retorno de recomendações personalizadas

**Principais habilidades demonstradas:**
- Operações matemáticas
- Entrada e validação de dados
- Formulação de recomendações

---

## 🛠️ Tecnologias Utilizadas
- **Python 3**

- Estruturação modular com **scripts separados**
- Lógica de programação aplicada a problemas reais
